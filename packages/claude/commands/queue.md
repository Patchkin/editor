description: Show what is waiting for you in Patchkin
---

Call the `patchkin_queue` tool and summarize what is waiting for this person.

- List each run with its ticket key and title, whether it is a plan waiting for a decision or a run waiting for approval, and the machine and agent.
- If nothing is waiting, say so in one line.
- Do not approve or send anything back. This command only reads.
- If the person names a run, offer `patchkin_run` with that run id so they can read the plan next.
